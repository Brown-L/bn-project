# M1 世界：課前準備與物種日誌

## 1. 世界觀
- 人類消失後約五萬年的地球。
- 人類曾經改變氣候與環境，但其影響在五萬年後仍持續存在。
- 生物經過長期演化，形成新的極端生態系。

## 2. 創作靈感
參考《路邊野餐》（史特魯伽茨基兄弟，1972）「未知環境」的概念。

> 將「無法完全理解的環境危險」轉化為五萬年後地球的生態特徵。

## 3. 三個極端生態系

### 黃石國家公園
嚴寒、地熱、極端化學環境與病毒共同塑造的孤立生態系。  
→ 地熱、寒冷、毒氣、季節性、重力異常

### 北大西洋深海熱泉
完全脫離陽光、由地球內部化學能驅動的生態系。  
→ 無光、高壓、熱泉、化學能、巨大環境梯度

### 南極洲
由巨大冰蓋、冰下水系與冰蓋變動支配的極端寒冷世界。  
→ 冰蓋、黑暗、低溫、冰下生態、長期氣候變動、時間異常

## 4. 生物設計方向
從各環境的極端條件出發，推導生物的：
- 外型與生理構造
- 移動方式
- 食性與生存策略
- 環境適應
- 物種間互動

**核心問題：不同生物如何在一個無法完全理解的環境中生存？**
