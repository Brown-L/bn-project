# NEON FAUNA — 物種雛形 01 物種日誌

這是一個以 p5.js WEBGL 製作的互動式賽博生物原型，依照 Blender 參考方向重建方形軀幹、四條分節方腿與六根多節觸角。

## 開啟方式

將 `index.html`、`sketch.js` 和 `style.css` 放在同一個資料夾，使用瀏覽器開啟 `index.html`。p5.js 從 CDN 載入，因此初次開啟需要網路連線。若瀏覽器限制本機頁面功能，可使用 VS Code Live Server 等靜態伺服器開啟資料夾。

## 互動特性

- 移動游標：觸角會追蹤游標投影到地面的落點；生物會注視、靠近或拉開距離。
- 點擊或觸控：在落點發出訊號波，近距離會使生物受驚後退。
- 「動態」按鈕：切換減少動態效果；亦會尊重系統的減少動態偏好。

## 檔案架構

- `index.html`：頁面結構、資訊面板與 p5.js 載入。
- `sketch.js`：3D 生物、步態、觸角 IK、游標互動與場景繪製。
- `style.css`：賽博龐克 HUD 與響應式版面。
