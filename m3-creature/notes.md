# THERMOPEDA QUADRATA 物種日誌

這是一個以 p5.js WEBGL 製作的互動式推測生態原型，舞台設定在 **五萬年後的黃石破火山口**。生物保留方形軀幹、四條分節方腿與六根多節觸角，並加入可重現的個體參數、生存指標、生長展示、形態分支選擇實驗與離線時間估算。

物種正式名稱為 **THERMOPEDA QUADRATA**（方形熱足體 / 破火山口共生體）。牠被設定為「碳基宿主 + 化能合成微生物」的共生體：熱泉提供 H₂S、Fe²⁺ 等無機化學源，共生微生物將其轉成宿主可用能量。這是作品的 **推測機制**，不是已證實的生物學事實。

## 開啟方式

將 `index.html`、`sketch.js`、`ecology.js`、`audio.js`、`style.css`、`vendor/` 與 `fonts/` 一起保留在同一個專案資料夾，使用瀏覽器開啟 `index.html`。p5.js 與字型都已放在專案內，不需要網路連線；若瀏覽器限制本機頁面功能，也可使用 VS Code Live Server 等靜態伺服器開啟資料夾。

## 互動

- 移動游標：觸角會追蹤游標投影到地面的落點；生物會注視、靠近或拉開距離。
- 點擊或觸控：在落點發出訊號波，近距離會使生物受驚後退，並讓外層 HUD 短暫出現掃描線／色散微故障。
- 長按地面約 0.6 秒或雙擊地面：種植一顆霓虹「化能能量晶體」。生物會進入覓食（FEEDING），走到晶體前停下、以觸角貼住晶體吸收；吸收完成後背甲爆閃，進入「能量充盈」。
- 快速甩動游標或近距離連續點擊：威脅值升高時，生物不再逃跑，而是縮起四肢、六根觸角收攏護頭，背甲轉為警戒紅光，進入防禦硬殼（DEFENSIVE）。
- 超過 10 秒完全不移動游標：生物下沉微趴，進入節能休眠（DORMANT），光芒轉為深海幽暗微光；直到游標再次靠近才會甦醒。
- 左側黑煙囪熱泉：距離太遠會低溫遲滯、身體偏冷藍；在舒適距離會自主漫遊取暖；太靠近則觸發過熱警戒光並後退。
- 行走時四隻腳會在地面留下約 1.6 秒的霓虹方塊光印。
- 「動態」按鈕：切換減少動態效果；亦會尊重系統的減少動態偏好。

## 生存指標與環境驅動行為

左側讀數不再是固定的 98.4%，而是每個模擬步驟更新的三個數值與一個綜合值：

- `ENERGY`：能量儲備。靠近熱泉化學源或在覓食時上升；移動、熱壓力與代謝會消耗。
- `HABITAT`：環境適合度。由局部溫度、pH 與個體耐受範圍共同決定；越接近熱泉，局部溫度越高。
- `SYMBIONT`：共生整合度。靠近化學源、吸收菌毯或投放結晶時上升；離開熱源會緩慢下降。
- `VITAL`：由能量 45%、環境適合度 35%、共生整合度 20% 組成的生存指標；同時顯示穩定／警戒／危急。

行為會依生存狀態改變，而不是只有固定漫遊：

- **探索 EXPLORE**：狀態良好時，前往種子產生的探索目標。
- **群聚 CLUSTERING**：能量低於 55% 或共生整合度低於 22% 時，靠近最近的化學結晶／菌毯，或熱泉化學源。
- **遷移 MIGRATING**：局部溫度超出個體耐受範圍，或季節脈衝觸發時，移動到較適合的熱梯度位置。
- **危險迴避**：間歇泉噴發或壓力超過 700 PSI 且距離過近時，進入受驚逃竄。
- 游標吸引、靠近／保持距離、點擊地面訊號、長按投放結晶、快速甩動防禦等原有互動均保留。

右側 `DRIVE` 會直接顯示目前的觸發原因，例如 `LOW ENERGY`、`THERMAL STRESS`、`SEASONAL MIGRATION`。

## 生長展示與個體檔案

- 首次載入會從 **PROPAGULE（繁殖體）→ JUVENILE（幼體）→ ADULT（成體）** 播放約 28 秒的生長展示；右側 `ONTOGENY` 顯示階段、進度與時間。
- 生長會讓方形軀幹、腿長與觸角節長同步變化；腿部接點會跟著軀幹比例重新定位。
- 個體由 seed 產生，包含軀幹比例、腿長、觸角節數、速度、代謝、化能親和與溫度／pH 耐受範圍。
- 個體參數會存到瀏覽器 `localStorage`；也可用 `index.html?seed=12345` 重現同一個初始個體。
- 遙測面板的 **INDIVIDUAL FILE / 個體檔案** 顯示 ID、seed、親代、世代數、形態參數、最新環境挑戰與最近的考驗紀錄。

## 形態分支選擇實驗

這不是自然演化模擬，而是一個單一挑戰的 **選擇實驗**。在遙測面板中選擇下一代的形態分支：

- **LONG LEGS / 長足**：腿長、移動速度與耐熱上限提高，身體略窄；適合快速穿越熱梯度。
- **BROAD HULL / 寬甲**：體寬與耐溫範圍提高，代謝略降；適合停留與保溫。
- **DENSE ANTENNA / 密觸角**：觸角節數、感測與化能親和提升；適合尋找化學源。

按下 **RUN THERMAL TRIAL / 熱梯度考驗** 後，環境會暫時變成低溫、酸性，生物必須在 20 秒內抵達熱泉化學源。挑戰結果會依移動速度、耐溫、能量與環境適合度計分。完成後，下一代會繼承親代參數、套用所選分支並加入小幅突變；挑戰條件（-6°C、pH 4.8、20 秒）與結果會寫入世代紀錄。

## 離線時間估算

關閉或切換頁面後，生態不會逐秒在背景運算。回到頁面時，系統會以離開時間差估算能量與共生整合度的變化，並在個體檔案與終端機標示 **「模擬估計」**，避免把估算值說成真實連續模擬。

## 聲音設計

聲音全部以 Web Audio API 即時合成，沒有額外音檔、沒有 CDN，離線開啟也能使用；不新增可見控制項，也不會破壞原有版面或既有操作。

- 第一次點擊、觸控或按鍵後自動啟動音訊（瀏覽器自動播放限制）。
- 低頻地熱底噪、間歇泉蒸氣嘶聲、低溫風聲與強酸嘶嘶聲會隨環境數值與生物距離變化。
- 生物行走時的伺服馬達低鳴與腳步聲（每步有細微音高抖動）、聲納 ping、餵食／吸收、防禦硬殼、噴發與終端機指令都有對應的合成音效。
- 拖動遙測滑桿時會發出極短促的刻度回饋聲；地熱底噪加入 110 Hz 泛音，讓一般筆電喇叭也能聽到低頻機械感。
- 按 `M` 可切換靜音；在終端機輸入框內打字時不會誤觸。頁面切到背景時音訊會暫停，回到前景後恢復，以節省電池。

## 黃石地熱遙測調控表

畫面右側的 **TELEMETRY DECK** 可展開／收合，所有數值都能用數字框直接輸入或拖曳滑桿，變更立即套用到 3D 生物：

- `AIR_TEMP`（-30～60°C）：低於 0°C 時地表網格轉為冰霜冷白、生物發抖且速度減半、觸角遲滯，並主動前往間歇泉取暖（WARMING）；高於 45°C 時背甲排熱燈加速閃爍、觸角上張散熱（COOLING）。
- `PH_LEVEL`（1.0～12.0）：pH < 3 啟動矽質硬殼（SHIELDED），外骨骼亮起琥珀金光、底盤壓低、觸角內收；pH > 10 觸角尖端高頻震顫；6.5～8 維持常態。
- `GEYSER_PSI`（0～1000）：每 6 PSI/s 自然累積，超過 750 或按 **FORCE ERUPT** 會引爆間歇泉。噴發時左側噴口射出高聳蒸氣與橘紅熱液、畫面震動並觸發掃描線故障，附近的生物會受驚逃竄；壓力歸零後才逐漸冷靜。
- `THERMO_FEED`：可投放 `GOLD`、`EMERALD`、`AZURE` 三種嗜熱菌群落。生物會趨前以六根觸角貼合吸食，完成後背甲邊緣光與足跡會同步變成該菌色。

## 指令終端機

在面板下方的 `BIO-COMMAND / 指令終端機` 輸入指令並按 Enter：

| 指令 | 效果 |
| --- | --- |
| `erupt` | 壓力拉滿並引爆間歇泉 |
| `blizzard` | 氣溫降至 -25°C |
| `acid` | pH 調至 1.5，啟動矽殼 |
| `feed [gold/emerald/azure]` | 在生物前方投放對應嗜熱菌 |
| `sonar`／`pulse` | 全場聲納脈衝，六根觸角同步指向聲源 |
| `scan` | 逐行印出核心體溫、外甲硬度、耐酸抗性、共生能量 |
| `reset` | 回復黃石基準環境 |
| `help` | 列出指令語法 |

## 檔案

- `index.html`：頁面結構、HUD、遙測資料表與指令終端機。
- `sketch.js`：3D 生物、步態、觸角 IK、游標互動、環境狀態機、熱梯度視覺與終端機指令。
- `ecology.js`：種子個體、生存指標、環境驅動行為、生長展示、選擇實驗、世代紀錄與離線估算。
- `audio.js`：以 Web Audio 即時合成的環境音與事件音效，無外部音檔。
- `style.css`：賽博龐克 HUD、遙測面板、終端機與響應式版面。
- `vendor/p5.min.js`：本機版 p5.js。
- `fonts/`：本機字型子集（Orbitron、DM Mono、Noto Sans TC）。

## 效能

- 以 30 FPS 為上限，降低筆電電池與內顯負擔。
- 2026-11-12 在 `972 × 540`、`pixelDensity(1)` 下量測：幼體／好奇狀態約 192 個 WebGL draw call，成體／遷移狀態約 209 個；每次改動後仍應重新量測。
- 新增的熱梯度場使用 9 個填充帶與 6 個環；熱泉另加 2 個微生物標記環，皆為可讀性需要的視覺元素。
- 盒體面、線框、環形裝飾與間歇泉蒸氣已分批繪製，減少了每帧的 WebGL draw call。
- 保留完整解析度、反鋸齒、燈光與原有視覺效果；未以降低畫質換取效能。
- 字型與 p5.js 均為本機資源，適合離線或高延遲網路環境。
- 音訊使用固定數量的常駐節點與短生命週期事件節點，不產生逐帧音訊配置；頁面切到背景時會暫停。
